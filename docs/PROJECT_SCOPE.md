# Project Scope

## Foundation

Platinum Modern DS uses HG-Engine as the runtime/battle foundation and Pokémon Platinum as the world/progression reference.

## Version 1 priorities

1. Reproducible HG-Engine build.
2. Audit and certify canonical Pokémon support through #1025.
3. Fairy type and modernized abilities/moves/items/evolutions.
4. High-value quality-of-life improvements.
5. Port the Platinum/Sinnoh world and story progressively.
6. Rebuild selected Elite Redux-style information UI natively for Nintendo DS.

## Explicit non-blockers for early playability

These features must not delay a playable build:

- Full UI replacement
- Custom Pokémon/forms
- Mercury-specific systems
- Large-scale side quests
- Clothing/customization systems
- Full randomizer
- Every optional postgame enhancement

The stock HGSS/HG-Engine UI remains the fallback until a replacement screen is certified.
